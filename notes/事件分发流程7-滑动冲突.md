# 滑动冲突

## 滑动冲突的本质

同一个触摸事件序列同时存在多个潜在消费者，而系统默认的事件分发规则无法满足当前业务期望，因此需要人为参与事件归属决策

```text
// 水平滑动冲突
ViewPager2(Horizontal)包含3个Page(ViewPager2(Horizontal))
```

### 如何解决

如何解决滑动冲突取决于要实现的业务期望!

## 场景分析-水平滑动冲突

```text
// 外层ViewPager2:outter
// 内层ViewPager2:inner
ViewPager2(Horizontal)包含3个Page(ViewPager2(Horizontal))
```

**期望:** 水平滑动时，优先inner滑动，inner滑不动时才让outter滑动。

**目前问题:** 只有outter才能水平滑动，inner只显示第一个page

### 问题分析

当pointer水平滑动时，outter在inner决定滑动之前就拦截了事件然后自己处理。

### 解决办法

**ACTION_DOWN时：**

inner要求parent禁止拦截事件

**ACTION_MOVE时：**

如果事件有水平滑动趋势:
1. child可以水平滚动则禁止parent拦截事件
2. 否则允许parent拦截事件

如果事件是垂直滑动趋势：

允许parent拦截事件(你这里直接禁止也能实现前面提到的期望)

#### 判断滑动趋势

```text
// 最小滑动举例
touchSlop = ViewConfiguration.get(context).scaledTouchSlop

// A:水平方向上的滑动距离dx > touchSlop
// B:垂直方向上的滑动距离dy > touchSlop

// A先满足则认为是水平滑动趋势
// B先满足则认为是垂直滑动趋势
```

#### 判断child是否能水平滑动
```text
// 使用如下方法判断
View#canScrollHorizontally()
View#canScrollVertically()    
```
